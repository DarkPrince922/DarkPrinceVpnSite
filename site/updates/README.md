# Манифесты обновлений

Сюда кладутся файлы, по которым приложения узнают о новой версии. Имена
жёсткие — их подставляет сам Tauri из адреса
`https://dprince.online/updates/{{target}}-{{arch}}.json`:

* `windows-x86_64.json` — клиент Windows;
* `linux-x86_64.json` — клиент Linux, только AppImage;
* `android.json` — клиент Android, формат свой, читает наш код.

Файлы **собираются в релизах приложений** и лежат там же, где установщики:
подпись в них настоящая, её ставит CI закрытым ключом. Поэтому в репозитории
сайта их нет — как нет и самих сборок. Как их сюда положить, написано в
README сайта, раздел «Положить приложения».

У каждой платформы свой файл, потому что версии у них расходятся: Android
может быть на 1.2.1, когда Windows ещё на 1.1.0. В схеме Tauri версия одна на
файл, и общий манифест заставил бы Windows обновляться до чужой версии.

## Формат

У Windows и Linux формат задаёт Tauri: версия, дата, и по блоку на платформу
с адресом и подписью. Подпись проверяет сам плагин — скачанный установщик это
чужой код на машине пользователя, и одного HTTPS для доверия к нему мало.

У Android формат свой, его читает `AppUpdater`:

```json
{
  "version": "1.2.2",
  "versionCode": 10202,
  "notes": "DarkPrince VPN 1.2.2",
  "url": "https://dprince.online/downloads/DarkPrinceVPN.apk",
  "sha256": "…"
}
```

Сравнение идёт по `versionCode`, а не по строке версии: строкой 1.10.0 меньше
1.9.0. Подписи здесь нет и не нужно — APK, подписанный другим ключом, Android
просто не установит, и это гарантия надёжнее нашей.

## Кеш

nginx отдаёт этот каталог с `Cache-Control: no-store`. Закешированный манифест
означает, что новая версия до приложений не доедет — при полностью выложенных
файлах.
