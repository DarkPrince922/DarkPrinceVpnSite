## Какую сборку брать

Приложение во всех трёх одно и то же — отличается только упаковка.

| Дистрибутив | Файл |
| --- | --- |
| Arch, Manjaro, EndeavourOS | [пакет pacman](/downloads/DarkPrinceVPN.pkg.tar.zst) |
| Ubuntu, Debian, Mint, Pop!_OS | [пакет .deb](/downloads/DarkPrinceVPN.deb) |
| Fedora, openSUSE и остальные | [AppImage](/downloads/DarkPrinceVPN.AppImage) |

Всё собрано под x86_64. Для другого процессора приложение собирается из
исходников — как, написано в
[репозитории](https://github.com/DarkPrince922/DarkPrinceVpnLinux).

## Установка

**Arch и производные:**

```
sudo pacman -U DarkPrinceVPN.pkg.tar.zst
```

**Ubuntu, Debian и производные:**

```
sudo apt install ./DarkPrinceVPN.deb
```

В обоих случаях зависимости подтянутся сами, а ярлык появится в меню
приложений.

**AppImage** ставить не нужно. Сделайте файл исполняемым и запускайте:

```
chmod +x DarkPrinceVPN.AppImage
./DarkPrinceVPN.AppImage
```

То же самое можно сделать мышью: свойства файла → «Разрешить выполнение».
Ярлык в меню при этом не появится — это особенность формата, а не недоделка.

## Вход

Войдите через Telegram или по почте — тем же аккаунтом, что и в боте.

## Два режима

**Прокси** — работает без пароля. Приложение поднимает локальный прокси и
прописывает его в настройки рабочего стола. Подходит браузерам и всему, что
уважает системный прокси.

**Весь трафик** — перехватывает всё, включая консольные программы. Система
один раз спросит пароль: без прав создать сетевой интерфейс нельзя.

## Не хотите наше приложение

Подписка в обычном формате, поэтому подойдёт
[Nekoray](https://github.com/Mahdi-zarei/nekoray/releases),
[v2rayA](https://github.com/v2rayA/v2rayA) или
[Hiddify](https://github.com/hiddify/hiddify-app/releases).

1. Скопируйте ссылку подписки в [кабинете](/cabinet.html), раздел
   «Подключение».
2. Добавьте её в клиент как подписку (Subscription или «Профиль по URL»).
3. Обновите список серверов, выберите узел и подключитесь.

Список обновляется сам, когда мы что-то меняем на своей стороне.

## Если не подключается

* Проверьте срок подписки.
* Попробуйте другой сервер.
* В режиме «Весь трафик» — проверьте, что дали пароль, когда система
  спрашивала.
* Не помогло — напишите в поддержку из приложения.
